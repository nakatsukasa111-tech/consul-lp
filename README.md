# 店舗経営ギャップ診断 LP

店舗を持つトレーナー・施術家に、公式LINEへ登録してもらい、無料の「店舗経営ギャップ診断」を受けてもらうためのランディングページ。

```
SNS → このLP → 公式LINE登録 → 診断（3分・20問）→ 結果 → 30分無料相談（10名まで）＋設計図1枚
```

- 1ページ完結／レスポンシブ（**スマートフォン優先**設計）
- ビルド不要。`index.html` をブラウザで開けばそのまま表示されます

## 構成

新PASONA（Problem → Affinity → Solution → Offer → Narrow Down → Action）に沿った12セクション。

| # | セクション | 役割 |
|---|---|---|
| 1 | ファーストビュー | 「プロの職人から、プロの経営者へ。」 |
| 2 | 思い当たることは、ありますか | 実際に相談される悩みを、その言い回しのまま |
| 3 | 腕を上げても、越えられない壁 | 技術の延長線上に答えがないと示す |
| 4 | **経営とは、いい仕事を続けるための技術** | ★差別化の核。お金の話ではないと宣言 |
| 5 | なぜ、私がそれを言うのか | 元プロ野球トレーナー→現役3店舗。権威付け |
| 6 | 見るべきものは、5つ | 収支・顧客・集客・継続・組織 |
| 7 | まず、現在地を測りませんか | 診断。3分・20問・0円 |
| 8 | 3分後に、これが見えます | 伸びしろの地図として提示 |
| 9 | 診断のあと、30分お話しします | 10名まで。無料の理由を本音で |
| 10 | 設計図を1枚お渡しします | 4つから、優先課題に合うものを |
| 11 | 受け取り方 | LINE登録 → 診断が届く → 3分で答える |
| 12 | FAQ ＋ 最終CTA | — |

## コピーのルール

「稼ぐ」「年商」など金銭を主語にした表現は**使いません**。対象がプロの職人気質であり、利益だけを目的にしていないためです。

| 使わない | 使う |
|---|---|
| 稼ぐ／売上を伸ばす | 守る／残す／続ける |
| 効率化する | 任せられるようにする |
| 集客する | 選ばれ続ける |
| 数字を管理する | 判断できるようになる |

## デザインの決めごと

参考にいただいたLP（人・組織創り Labo）のトンマナに合わせています。

| 要素 | 値 | 使い方 |
|---|---|---|
| 地 | 白 `#ffffff` ／ ウォームグレー `#f4f2ec` ／ 薄いオレンジ `#fdf1ea` | 明るいまま通す |
| 濃色 | `#1c1c1a` | 最終CTAとフッターのみ |
| アクセント | オレンジ `#d2673c` | 見出し・ボタン・CTA帯 |
| 見出し書体 | Zen Kaku Gothic New 900 | — |
| 本文書体 | Noto Sans JP | — |

**参考LPから取り込んだ型**

- セクション見出しは「大きなオレンジの欧文 ＋ 日本語見出し」。見出し下の罫は使わない
- 主要セクションの背景に、画面幅いっぱいの薄い巨大欧文を敷く
- CTA帯はベタのオレンジ。小さな欧文ラベル → 見出し → 白いボタン（主文＋補足＋矢印）
- 角丸は小さく（`--r: 6px`）。ピル型のボタンは使わない
- カードは影ではなく1pxの枠線で仕切る
- 矢印は `→`（細い線）

色は `assets/css/style.css` 冒頭のトークンで一元管理しています。

## 公開前にやること

### 1. 公式LINEのURLを入れる

CTAボタン（本文4箇所＋追従1箇所）のリンク先は `#LINE_URL` で統一しています。

```bash
sed -i 's|#LINE_URL|https://lin.ee/xxxxxxx|g' index.html
```

※ 未設定の間は、押してもページ先頭に飛ばないようJS側で抑止しています。

### 2. 写真・図を差し替える

`assets/img/` の各SVGに、**どんな写真を入れるかが画像内に書いてあります**。同じ比率の写真に差し替え、`index.html` の `src` の拡張子を変更してください。

| ファイル | 入れるもの | 比率 |
|---|---|---|
| `hero.svg` | 中務さんが自店舗に立っている写真。スタッフと話している場面が理想 | 16:9 |
| `after-hours.svg` | 営業後、一人でPCに向かう店長の後ろ姿 | 4:3 |
| `hands.svg` | 施術中・指導中の手元のアップ（顔は写さない） | 3:2 |
| `team.svg` | 朝礼やミーティング、全員の集合写真 | 3:2 |
| `portrait.svg` | 中務さんの顔写真（上半身） | 3:4 |
| `career.svg` | プロ野球・MLB時代、または選手の指導風景 | 4:3 |
| `five-areas.svg` | 5つの領域の関係図（写真ではなく作図） | 16:9 |
| `phone.svg` | スマホで診断に答えている手元 | 4:3 |
| `result.svg` | **診断結果画面のスクリーンショット** | 4:5 |
| `meeting.svg` | オンライン相談の様子 | 4:3 |
| `blueprint-1〜4.svg` | 4つの設計図のサムネイル | 1:1 |
| `step-1〜3.svg` | LINE登録・診断到着・回答中の画面 | 1:1 |

`result.svg` を実物のスクリーンショットにすると、いちばん効きます。
