# ジム経営ギャップ診断 LP

パーソナルジム・小規模ジムの経営者に、**公式LINEへ登録してもらい、無料の「ジム経営ギャップ診断」を受けてもらう**ためのランディングページ。

```
SNS → このLP → 公式LINE登録 → 診断（3分・20問）→ 結果 → 30分無料相談（10名まで）
```

- 1ページ完結／レスポンシブ（**スマートフォン優先**設計）
- ビルド不要。`index.html` をブラウザで開けばそのまま表示されます

## デザインの決めごと

| 要素 | 値 | 使い方 |
|---|---|---|
| 地 | ウォームアイボリー `#f7f3eb` ／ `#efe9dd` | 基本の背景 |
| 濃色 | ネイビー `#132a44` | 見出し・ボタン・反転セクション |
| アクセント | 真鍮色 `#c9892c` | 数字・キーワード・CTAボタン |
| 補助 | `#8fa9c0` | 罫・補助要素 |
| 見出し書体 | Zen Kaku Gothic New 900 | 引き締まったゴシックで権威性を出す |
| 本文書体 | Noto Sans JP | 本文 |
| 数字・欧文 | Cormorant Garamond | 大きな数字とラベル。細いセリフで格を出す |

色は `assets/css/style.css` 冒頭のトークンで一元管理しています。

**方針**

- 小さな文字での細かい説明は置かず、**大きな文字と余白**で読ませる
- 角丸はほぼ使わない（`--r: 2px`）。区切りは**細い罫線**のみ
- 差し色は「文字の一部」と「ボタン」だけに使い、面を塗らない
- Cormorant は既定が旧様式数字（`10` が `IO` に読める）のため、
  数字を出す箇所はすべて `font-variant-numeric: lining-nums` を指定しています

## 公開前にやること

### 1. 公式LINEのURLを入れる

CTAボタン5箇所のリンク先は `#LINE_URL` で統一しています。一括置換してください。

```bash
sed -i 's|#LINE_URL|https://lin.ee/xxxxxxx|g' index.html
```

※ 未設定の間は、押してもページ先頭に飛ばないようJS側で抑止しています。

### 2. 画像を差し替える

`assets/img/` のSVGを写真・イラストに置き換えるだけです。
ファイル形式を変える場合は `index.html` の `src` の拡張子も変更してください。

| ファイル | 入るもの | 推奨比率 |
|---|---|---|
| `hero.svg` | ヒーローのメインビジュアル | 4:3 |
| `busy.svg` | 現場に追われる店長のイラスト | 4:3 |
| `order.svg` | 「手をつける順番」の図解 | 3:2 |
| `result.svg` | **診断結果画面のスクリーンショット** | 4:5 |
| `relief.svg` | 安心して答えられる様子 | 4:3 |
| `consult.svg` | オンライン相談の様子 | 4:3 |
| `profile.svg` | 中務さんの顔写真 | 3:4 |
| `step-1〜3.svg` | 受け取り方3ステップのイラスト | 1:1（円形に切り抜かれます） |

`result.svg` は実際の診断結果画面のスクショに差し替えると、いちばん効きます。

### 3. 数字を確認する

原稿に入れてある可変値です。変更する場合は `index.html` を直接編集してください。

- 診断：**3分・20問・0円**
- 相談：**10名まで**・30分・無料
